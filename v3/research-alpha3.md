# Alpha 3 research and audit — 2026-11-26
Three scoped desk-review passes, not three independent user studies.
## Pass A: interaction and competitors
NN/g heuristics https://www.nngroup.com/articles/ten-usability-heuristics/ and progressive disclosure https://www.nngroup.com/articles/progressive-disclosure/ : immediate link/preset/download, no mandatory dialog, stable controls; clear reason when unavailable. Original UI functions show_window, hide_window, _read_clipboard, _monitor_clipboard and popup.py establish the tray behavior. V3 alpha2 only checks clipboard while WebView focused, rejects new URLs when previous auto-filled draft stays, and suppresses identical copies indefinitely. MediaHuman https://www.mediahuman.com/howto/add-to-youtube-mp3-converter.html auto-adds detected URLs; QuickClip should fill the URL without auto-starting downloads or stealing focus. Open Video Downloader https://github.com/jely2002/youtube-dl-gui/ supports shortcuts and notifications. Add shortcut, clear draft, pending-link action, and visible status.
## Pass B: Windows and visual design
Microsoft https://learn.microsoft.com/en-us/windows/apps/desktop/modernize/ui/apply-rounded-corners : DWM rounding is a hint, tool windows may not get it. Explicit owned-window GDI region https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowrgn and https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-createroundrectrgn can give verifiable clipping, refresh on resize/DPI. Original popup implements clipping and DPI. V3 alpha2 styles native rectangle only, CSS theme partially overrides colors. Use full theme tokens for every surface and contrast-tested accent colors; W3C https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html and MS https://learn.microsoft.com/windows/apps/design/style/color. Test computed colors in actual WebView, not only settings value. Do not assume native visuals from CSS.
## Pass C: reliability and next product gaps
Microsoft clipboard sequence https://learn.microsoft.com/en-us/windows/win32/dataxchg/using-the-clipboard ; Tauri clipboard Rust API https://v2.tauri.app/plugin/clipboard/ . Detect changes independent of WebView focus; only retain valid link in RAM, no background network request; don't overwrite manual edits. Original RC2 has configurable organizer DB, notification, concurrent downloads, retry/pause, preview thumbnail, explicit browser authentication, diagnostics, AI opt-in, partial file retention and portable tools. Rechecked original profiles/settings/models/UI/organizer/worker from baseline index. Current Rust still lacks these in full; don't claim parity. Parabolic https://github.com/NickvisionApps/Parabolic and releases https://github.com/NickvisionApps/Parabolic/releases show rich format options and portable dependencies; current Rust manual tool selection remains release blocker. yt-dlp https://github.com/yt-dlp/yt-dlp supports structured progress templates; make status truthful. NN/g https://www.nngroup.com/articles/visibility-system-status/ : actionable feedback. Current queue redraw on each polling tick loses keyboard focus; use keyed or signature-limited renders, native progress not CSP-blocked inline CSS. Future: real-site fixtures, explicit private auth with redaction, queue concurrency, notification, custom presets, dependency bootstrap and recovery before stable release.
