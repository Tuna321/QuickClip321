# UX research and engineering rules
Sources reviewed: https://www.nngroup.com/articles/testing-ai-methodology/ ; https://www.nngroup.com/articles/ten-usability-heuristics/ ; https://www.nngroup.com/articles/progressive-disclosure/ ; https://www.nngroup.com/articles/usability-testing-101/ ; https://learn.microsoft.com/en-us/windows/win32/uxguide/winenv-notification (older Windows guidance; use interaction principles, test on Windows 11) ; https://learn.microsoft.com/en-us/windows/apps/design/accessibility/designing-inclusive-software ; https://v2.tauri.app/learn/system-tray/
## Design contract
- This is a tray utility, not a dashboard or marketing landing page. No hero, app-sized navigation chrome, welcome screen, mandatory account or setup on every launch.
- One tray click opens a compact, taskbar-free, frameless flyout adjacent to tray icon, within monitor work area. Another click / Escape / outside click dismisses without cancelling work. Native dialogs must not be dismissed by focus loss. Preserve draft while hidden.
- Link, preset, format, resolution, preview, destination, Download, progress are immediate; secondary controls in Advanced, consistent positions. Disable unavailable commands with reason; don't silently reset chosen values. Preserve the user's mental model, English strings and brand.
- Calm visual hierarchy: one purple primary action, restrained surfaces, neutral backgrounds, no decorative motion, stable widths, predictable spacing, small status line. Light/dark/system, keyboard navigation, visible focus, high contrast and DPI validation. Respect reduced motion.
- Feedback: distinguish analyzing, downloading, converting, verifying, ready, failed, cancelled and paused; report real speed/ETA when available. Never show success for a partial file. Recoverable errors give a next action and retain source.
- AI is an optional tool for design critique and local assistance, not a substitute for real user testing. Use task flows, screenshot at 100/125/150% DPI, keyboard tests, actual process and file checks. Independently critique as novice, experienced editor, accessibility tester, security reviewer and release engineer. Do not invent user testing or ratings.
- Test scenarios: launch hidden, tray toggle 10x, outside click, Escape, dialog, paste a link, complete synthetic download, preview failure still allows download, playlist requires consent, cancellation preserves source, duplicate detection, restart recovery, custom destination and settings.
- Measure task completion, clicks, time to usable popup, idle CPU/RAM, total time to ready media. Compare same machine/tools/fixtures. No performance claims from EXE size alone.
