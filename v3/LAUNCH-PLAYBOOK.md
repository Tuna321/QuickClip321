# QuickClip321 public beta launch playbook

## Positioning
A free, open-source Windows tray-first video/audio downloader. Copy a media link, click the tray icon, press Download. With clipboard capture enabled and setup completed, no full-size window or manual paste is needed. No automatic download without explicit user action. No speed ranking or claim of exclusive tray/clipboard features: comparable tools offer similar features.

## Evidence and research
- https://www.reddit.com/r/youtubedl/comments/1fdd165 : users discuss reducing repetitive CLI and clipboard steps. Anecdotal, not market size.
- https://www.reddit.com/r/youtubedl/comments/1l4o8vt : clipboard monitoring reliability matters.
- https://github.com/NickvisionApps/Parabolic/issues/1738 : user expects clipboard capture to open a download flow; setup failures can obstruct it.
- https://github.com/akcware/ytdlp-gui : clipboard suggestion and completion toast are available elsewhere. Differentiate through the complete tray-first workflow, not novelty claims.
- https://news.ycombinator.com/showhn.html and https://news.ycombinator.com/newsguidelines.html : personally built usable projects, authentic maker participation, no coordinated voting; write your own HN text.
- https://help.producthunt.com/en/articles/17834537-4-build-your-product-page : direct product link, descriptive tagline, real gallery and maker identity.
- https://www.reddit.com/r/SideProject/about/rules/ and https://www.reddit.com/r/youtubedl/about/rules/ : rules pages retrieved without visible detailed rules. Recheck in-app or ask moderators before posting.

## Rollout (not posted)
1. Start with a small group of Windows editors and creators. Ask them to try first launch and a permitted download without coaching. Request version, setup issues, time to first successful download, and what felt confusing. Do not collect private URLs or credentials.
2. Publish a short demo to the creator's own accounts. Show real footage: copy a permitted media URL, click actual system tray icon, link autofilled, press Download, return to editor, show notification and file. No fabricated speed, no misleading time compression of network transfer. Separate first-use setup from everyday use.
3. Share an English maker post in relevant communities where allowed, with a real demo and request for concrete feedback. No repetitive cross-post spam, no unsolicited DMs, no paid/fake stars or vote requests. HN maker writes own submission and participates. Product Hunt after more first-use feedback.

## Launch health
Track public release asset downloads (not unique people or active users), GitHub stars, issues and successful first-run reports. Snapshot manually before promotion and after 24 hours / 7 days. Do not add telemetry without explicit consent. Goals are planning targets, not predicted results: 10 first-run reports, 3 distinct external testers, prioritize all reproducible blockers. No paid promotion needed initially.

## Beta disclosures
Unsigned Windows x64 EXE, WebView2, first-use verified media tools may require approximately 170-200 MB. Run on startup defaults to on, opt-out in settings. Partial resume only on eligible single Original downloads. Clean-machine certification and complete native UI parity open. No universal source compatibility claim.
