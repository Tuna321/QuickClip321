# Alpha 4 review log — 2026-11-26
Evidence: screenshot supplied by user, original popup.py / preview.py / profiles.py, current main.rs / app.js / CSS, actual compiler/tests, primary docs. Ten targeted audit topics, not ten complete independent rewrite cycles.
1. Visual defect: white native frame around the dark window in screenshot; Tauri docs explicitly describe white border with undecorated shadow enabled. Disable shadow, dark native initial color, increase physical clipping diameter and add coherent themed inner border. https://v2.tauri.app/reference/config/ ; https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwmwindowattribute
2. Layout: preserve original 600-ish compact tray flyout. Reduce excess bottom whitespace and idle progress; 16px shell radius, 8–12px control radius. Actual screenshot required, not merely DOM.
3. Tray: original popup.py uses physical coordinates, monitor work area, anchor and DPI; Rust must preserve tray semantics. Current custom position only persisted, not applied immediately. Apply on save and preview; test actual top-left position.
4. Progressive disclosure: custom XY should appear only for Custom. No need to display controls irrelevant to selected mode. https://www.nngroup.com/articles/progressive-disclosure/
5. Contextual help: original has help icons. Add keyboard-focusable info buttons with concise text and accessible names. https://www.nngroup.com/articles/tooltip-guidelines/
6. Thumbnail: original preview.py fetched bounded image; Rust previously only returned text. Use yt-dlp bounded thumbnail-only output, isolated temp folder, limit encoded bytes and reject non-image formats. Metadata fallback remains usable. https://github.com/yt-dlp/yt-dlp/blob/master/README.md
7. Competitor check: Parabolic explicitly includes thumbnail preview; MediaHuman filters clipboard and preserves files when removing queue records; Open Video Downloader offers shortcuts and notifications. https://github.com/NickvisionApps/Parabolic/releases ; https://www.mediahuman.com/howto/user-interface-in-detail5.html ; https://github.com/jely2002/youtube-dl-gui
8. Progress: original worker sends actual speed/ETA; current Rust only percentage. Parse yt-dlp template and show separate postprocessing status; idle shouldn't show a full bar from old history. Multi-item overall progress still needs semantics.
9. Safety: keep thumbnail path job-owned; no remote image in privileged WebView, no shell interpolation, no new crate needed after offline base64 dependency failed. Test encodings and non-image rejection. Preview must not start hidden. No changes to unrelated files.
10. Release/parity: original custom profiles, organizer rules, pause/resume, concurrent jobs, diagnostics, notification, authenticated jobs, tool bootstrap remain major blockers. Competitor media-saver describes restart recovery and verified updates, useful as design reference, not independently verified: https://github.com/softoblivion/media-saver. Keep alpha3 binary and state backup; no stable release until interactive and clean-machine gates pass.
